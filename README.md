# 8-BIT-CPU-project

## The Problem is...

This 8-bit processor I’m building is, overall, quite complex and involves so many elements that I’ve started to find myself unable to tackle certain aspects. As a result, I’ve been working on this project constantly, every day, and when I suddenly had to get it up and running, I began to overlook certain details; as the days went by, it became even more complicated and difficult to understand. For now, I’m taking a break from this project, but I’ll set aside some time on certain days to revisit it. When I reorganize the code and try to get it up and running again in a simpler way, I’ll have a better understanding of how difficult it is to build something and how simple it is to tear it down.

## Problem with Binary system

This is a processor designed to operate in the binary number system, but I’m thinking of setting that aside; I believe it will be easier and more understandable to write this project using the decimal system.
