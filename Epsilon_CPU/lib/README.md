### İnterrupts C and ASM

## C codes

Actually, I could have done this using pure C code, but using assembly will make me feel as though I’m building an operating system. Of course, my goal isn’t to build an operating system—it’s to build a processor. Ultimately, this is a virtual processor, and in order for the virtual processor simulation to receive input from the user, I need to create a virtual driver called “keyboard interrupts.”

## ASM

It would be a good idea to use C code alongside ASM, because I think compiling and processing data from ASM files together with C code will be both fast and fun. Of course, I could use just ASM or just C, but relying on just one language can either greatly simplify the task or lead to the exact opposite outcome. When ASM, C, and C++ are used together, they can produce truly amazing projects.
