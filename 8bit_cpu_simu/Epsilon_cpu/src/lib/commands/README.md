

# COMMANDS

These commands are necessary for the CPU to operate autonomously,
because the processor behaves according to the system, not the user (though, of course, this is made possible by software). Since this is a low-level system,translating it into a language people can understand is difficult and tedious. 
The commands I’ve written include classic CPU instructions like READ, WRITE, ADD, LDA, and LDB, but the ones I’ve included are essential for basic and general needs.
If you want to understand a processor better, you can review the processor documentation released by AMD or Intel...
